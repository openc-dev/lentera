# Lentera - Lending & Tracking Application

A simple and secure laboratory asset lending and tracking system. This project was developed to fulfill the exam practicum assignment and later adapted for production deployment.

## Tech Stack

- **Frontend:** Next.js 16, React 19, TypeScript
- **Styling:** Tailwind CSS v4
- **Database & Auth:** Supabase (PostgreSQL)
- **API Layer:** Vercel Serverless Functions (Next.js API Routes)
- **Deployment:** Vercel
- **Original Backend:** Laravel
- **Libraries:** Axios, bcryptjs, qrcode.react, @vercel/analytics
